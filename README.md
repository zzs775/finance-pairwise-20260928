# ABS Cash Flow Waterfall Engine

标准库实现的 Python 3.13 ABS（资产支持证券）单池现金流瀑布引擎。全部金额、费率
与比例使用 `decimal.Decimal` 固定尺度：货币最小单位 `0.01`，费率 `1e-10`，并设置
货币量级上限（默认 `999,999,999,999.99`），越界按分类异常失败，不产生静默溢出。

## 规则总览

- **严格区分账户**：利息账户、本金账户、储备金账户三者独立；每一笔资金移动都
  显式借记来源、贷记目标，审计轨迹同时记录前后余额与借贷方向。
- **负数与结构校验**：负现金、重复档位 ID、重复优先级、优先级顺序缺失或引用未知
  档位、触发器缺参或引用不存在的优先级、当期缺失冻结指标，均在执行前分类失败
  （`NegativeCashError`、`DuplicateTrancheError`、`PriorityConflictError`、
  `TriggerConfigurationError`、`CashOverflowError` 等）。
- **分步执行**：费用 → 证券利息 → 储备补足 → 证券本金 → 储备释放 → 损失分摊；
  每一步的前后余额写入审计轨迹，同一笔现金或损失不会被重复使用。
- **顺序与按比例**：本金支持 `sequential`（严格优先级）与 `pro_rata`（按当前档
  位余额比例）。按比例在最小货币单位（分）上分配。
- **稳定最大余数法**：余数先比较“精确份额减去整数份额”的小数余量，相同余量按档
  位 ID 字典序分配；输入顺序变化不改变余数归属，规范化报告字节一致。
- **冻结触发器**：触发器只读取当期 `indicators` 快照（如逾期率 `dlq`），命中后
  切换到题内指定的优先级画像；引擎绝不回写资产池。多个触发命中时按配置顺序第一
  个生效，其余仅记录在结果里。
- **失败整体回滚**：任一步骤抛错，本期所有账户、档位余额与累计项恢复到期初快照，
  丢弃部分审计行；多期引擎不会写入失败期。

## 利息/本金转换

每一档当期利息 = 期初档位余额 × 票息率 + 上期结转利息欠付。利息支付的资金来源
顺序固定为：

1. 利息账户
2. 储备金账户（先动用已积累储备）
3. 本金账户（仅当 `allow_interest_principal_switch` 为真）

费用同样先取利息账户，再按开关决定是否可由本金垫付。利息步骤与储备补足之后若有
剩余利息，且开关打开，则从利息账户划入本金账户用于本金分配；开关关闭时利息剩余
保留为未分配利息，绝不与本金混用。未付清利息作为 `interest_shortfall` 结转下期。

## 储备金

- 目标储备 = `max(beginning_pool_balance × target_rate, min_balance)`。
- 补储备在费用与利息之后，从利息（再按开关从本金）支取。
- 储备释放发生在本金分配之后：仅当未命中触发器且 `releasable=true` 时，把超出
  目标的储备划入本金账户并按当前本金模式分配；锁定期内储备不释放。

## 损失穿透

已实现损失按次级优先顺序（seniority 数值大者先吸收）逐档减记档位余额；损失总额
超过全部未偿票据余额时抛 `InsufficientFundsError` 并整体回滚。Oracle 断言：

- 资产池现金来源 = 各档利息 + 各档本金 + 费用 + 储备净变化 + 未分配额；
- 已实现损失 = 各档减记之和，且票据余额总下降 = 本金偿还 + 损失减记。

## 逐货币单位 Oracle

`abs_waterfall/oracle.py` 提供独立于生产分配器的参考实现：把金额展开成整数个
`0.01` 单位，先按精确份额发放整数部分，再逐单位按静态最大余量（同余量按 ID）
分配。`assert_cash_closure` 与 `assert_loss_closure` 对单期结果做精确闭合断言。
测试用数百组随机权重交叉验证生产实现与 Oracle 完全一致。

## CLI

```bash
python -m abs_waterfall.cli fixtures/multi_period.json --check-oracle --indent 2
```

输出规范化 JSON（键排序、货币为两位小数字符串、ID 映射按键排序）。夹具格式见
`fixtures/multi_period.json`，包含三期场景：正常顺序偿付、逾期触发器命中切按比例
并吸收损失、指标回落后恢复正常画像。

## 运行测试

```bash
python -m compileall -q abs_waterfall tests
python -m unittest discover -s tests -v
```

覆盖场景：触发前后画像切换、利息/本金转换与利息欠付结转、储备补足与锁定期不
释放、按比例尾差稳定归属、损失逐级穿透、失败整体回滚、负数/重复/优先级/触发器
缺参分类失败、多期连续性、输入乱序报告一致性与 CLI 端到端闭合。
